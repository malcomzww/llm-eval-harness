# The reporting rule, demonstrated

Generated by `python scripts/generate_results.py`. Do not edit by hand.

- Date: 2026-08-25
- Hardware: irrelevant. These are statistical properties, not timings
- Seed: 0 (fixed; the file regenerates identically)
- Sample size: 200 per system
- Reproduce: `python scripts/generate_results.py`
- Data: synthetic Bernoulli scores with known success rates

Synthetic on purpose. The claim under test is that this harness
refuses to report a difference it cannot support, and real model
noise would obscure that rather than demonstrate it.

## Two identical systems

Both draw from the same 70% distribution, so the true difference is
exactly zero.

- observed delta: **-0.0100**
- 95% CI: [-0.1000, +0.0850]
- **reportable: no** — the interval includes zero

The point estimate is not zero, and never will be. Quoting it as an
improvement is the most common way eval results mislead, so the
harness labels it unreportable instead.

## Two systems that genuinely differ

60% versus 70%, same sample size.

- observed delta: **+0.1700**
- 95% CI: [+0.0850, +0.2600]
- **reportable: yes** — the interval excludes zero

## Kappa separates a good judge from a coin flip

| judge | agreement with human | Cohen's kappa |
|---|---|---|
| 85%-agreeing | 86% | **0.710** |
| coin flip | 50% | **0.008** |

Raw agreement makes the coin flip look respectable. Kappa subtracts
the agreement expected by chance and puts it near zero, which is why
this harness calibrates on kappa rather than accuracy.

## How large a golden set needs to be

Samples per arm to detect a given difference at 80% power, two-sided
alpha 0.05, sd 0.5:

| difference to detect | samples per arm |
|---|---|
| 1% | 39,245 |
| 2% | 9,812 |
| 5% | 1,570 |
| 10% | 393 |
| 20% | 99 |

Worth computing before building the set rather than after: a
100-item golden set cannot resolve a 2-point difference, and no
amount of careful judging changes that.

## Limitations

- Synthetic Bernoulli data. Real eval scores are often bounded,
  skewed or bimodal; the bootstrap handles those, but this file does
  not demonstrate it on real distributions.
- Sample sizing uses a normal approximation, which is loose for very
  small n or extreme proportions.
- Kappa here is binary. Multi-category and weighted kappa behave
  differently and are not established by this file.
